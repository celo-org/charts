# succinct-game-monitor-embedded

![Version: 0.1.0](https://img.shields.io/badge/Version-0.1.0-informational?style=flat-square) ![Type: application](https://img.shields.io/badge/Type-application-informational?style=flat-square) ![AppVersion: 0.1.0](https://img.shields.io/badge/AppVersion-0.1.0-informational?style=flat-square)

Single in-process OP Succinct game monitor. Discovers fault-dispute games on-chain and runs cost-estimation (witness generation + SP1 prove) in one process, bounded by a shared cgroup memory budget. Replaces the subprocess-based succinct-game-monitor.
